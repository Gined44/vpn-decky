# vpn-decky

VPN-клиент для Steam Deck (Decky Loader), использующий [sing-box](https://github.com/SagerNet/sing-box) как ядро.

Поддерживает vless, hysteria2 и trojan-ссылки — как одиночные ключи, так и подписки. Написан под минимализм: без split-tunneling, без выбора DNS и прочих настроек — просто вставил ключ и подключился.

## Возможности

- Добавление профилей по ссылке (`vless://`, `hysteria2://`/`hy2://`, `trojan://`)
- Добавление подписок по URL (список ключей, обычным текстом или в base64)
- Автообновление подписок в фоне при каждом запуске плагина
- Защита от коллизий имён между разными подписками (суффиксы `-2`, `-3`...)
- Автоскачивание и проверка бинарника sing-box при первом запуске — ничего докачивать руками не нужно
- Автовосстановление соединения после перезагрузки системы
- Пинг серверов в обход VPN-туннеля (через физический интерфейс)
- Сетевая диагностика в разделе "Статус": физический интерфейс, состояние tun-интерфейса, доступность интернета, доступность сервера VPN
- Скрытый режим разработчика (5 быстрых кликов по мелкой подписи "vpn-decky" внизу статуса) — показывает последние строки лога sing-box, для отладки

## Установка

1. Закинь файлы плагина в `/home/deck/homebrew/plugins/vpn-decky`
2. Запусти Game Mode
3. QAM → Decky → vpn-decky → дождись загрузки (первый запуск сам скачает нужный бинарник sing-box, нужен интернет)
4. Вставь свой ключ

Готово, пользуйтесь.

## Поддерживаемые протоколы

- VLESS (включая TLS/Reality, WS/gRPC-транспорт)
- Hysteria2
- Trojan (TLS, WS/gRPC-транспорт)

VMess и Shadowsocks пока не поддерживаются.

## Известные ограничения

- Нет split-tunneling / выбора отдельных приложений для обхода VPN
- DNS зафиксирован на 1.1.1.1, без возможности сменить из интерфейса
- При сетевых ошибках (SSL) код может откатываться на соединение без проверки сертификата — это осознанный компромисс ради работы на нестабильных сетях/за DPI, а не случайный баг. Подробности в коде (`_build_ssl_context`, фоллбек на `ssl._create_unverified_context()`)
- Нет kill switch — если процесс sing-box упадёт, трафик пойдёт напрямую в обход VPN
